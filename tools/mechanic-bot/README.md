# Бот механика — прототип (Telegram → Google Таблица)

Временный учёт работ СТО, запущен 11.10.2026, пока ремонты не умеют этого в EV8 Ops.
**Это не код продукта**: здесь лежит копия того, что сейчас работает, как образец
для переноса в EV8 Ops. Комментарии и тексты в коде — по-русски и по-грузински, как
написано в Apps Script; в продукт он в таком виде не идёт.

## Что делает

Механик в Telegram (интерфейс на грузинском) открывает ремонт: VIN (полный, последние
6 знаков или QR `t.me/<бот>?start=<VIN>`) → фото 1–5 → причина (износ, ДТП, вина
арендатора, гарантия, плановое ТО) → работы из справочника нормо-часов с количеством,
работа вне списка — текстом или голосом → комментарий. Заявка с фото уходит
согласующим (главный механик и владелец) с кнопками «Согласовать / Отклонить».
Закрытие: фото «после» → запчасти из складской таблицы (списываются как «Расход
(ремонт)» с VIN) → готово. Простой мопеда = от открытия до закрытия, в часах.
По понедельникам 10:00 владельцу — сумма к оплате по каждому механику и кнопка
«Оплачено»: тикеты получают статус «Оплачен», запись в журнале выплат, механику
уведомление.

Сумма работы = кол-во × норма (мин) / 60 × ставка; норма и ставка записываются в
строку работы в момент заявки, правка справочника старые суммы не меняет. Ставка —
50 ₾/ч (как `labourRateTetri` в ServiceJob).

## Где живёт

```
Telegram ──webhook──▶ Cloudflare Worker (worker.js) ──POST──▶ Apps Script /exec (Code.gs) ──▶ Google Таблица
                       сразу отвечает 200                       doPost → обработка            листы ниже
```

- **Code.gs** — Google Apps Script, привязанный к таблице «EV8 — ремонты (бот
  механика)» в Drive Kardu; опубликован как веб-приложение. Токен бота — в Script
  Properties, в коде и таблице его нет. Фото — в папку Drive рядом с таблицей.
- **worker.js** — Cloudflare Worker. Нужен потому, что Apps Script отвечает на POST
  редиректом 302, Telegram считает доставку неудачной и очередь апдейтов встаёт
  (проверено 11.10.2026: без посредника бот ответил только на первое сообщение).
  Worker отвечает 200 сразу и пересылает апдейт в `/exec` в фоне. Повторы Telegram
  Code.gs отбрасывает по `update_id`.
- **test/** — имитация Apps Script и Telegram в Node, сценарий целиком: создание
  листов, заявка → согласование → закрытие → склад → отчёт → выплата, права,
  повторы апдейтов, двойные нажатия, поиск VIN. Запуск: `node test/run.js`.

## Таблица (листы)

| Лист | Что | Ляжет в EV8 Ops как |
|---|---|---|
| Настройки | ставка, Telegram ID владельца и согласующих, ID складской таблицы | `RentalSettings` / секреты сервера |
| Механики | имя, Telegram user_id, своя ставка | `Workshop` (+ привязка Telegram) |
| Справочник работ | код, категория, название ka/ru, норма в минутах, активна | новая таблица — справочник работ |
| Мопеды | VIN, модель, активен | `Vehicle` |
| Тикеты | открыт/закрыт, механик, VIN, причина, статус, согласование, простой, фото | `ServiceJob` (+ `StoredFile`) |
| Работы | тикет, код, кол-во, норма, ставка, сумма | новая таблица — строки работ в ремонте |
| Запчасти по тикетам | тикет, SKU, кол-во, списано ли | `ServicePart` / `StockMove` |
| Журнал выплат | выплата, механик, сумма, тикеты | новое — выплаты мастерским |

Имена людей в этой копии заменены на «მექანიკოსი 1/2»; в живой таблице — настоящие.
В репозиторий не попадают Telegram ID, токен, адрес `/exec` и данные клиентов.
