# Сервер EV8 Ops — как поднять и как обслуживать

Дата: 22.09.2026. Составлено до того, как сервер появился, поэтому **ни одна команда отсюда ещё не
выполнялась на живой машине**. Локально проверено то, что можно: compose-файлы собираются
(`docker compose config`), `backup.sh` проходит `sh -n`. Первый прогон делаем вместе.

Устройство — по практикам §2: один сервер, один Traefik, два compose-проекта на общей сети.
Тестовый стенд крутит `develop`, прод — тег `X.Y.Z`.

```
        :80 :443
           │
       ┌───▼────┐   сеть ev8-edge
       │Traefik │──────────────┬──────────────┐
       └────────┘              │              │
                         ┌─────▼────┐   ┌─────▼──────┐
                         │ ev8-ops  │   │ev8-ops-test│   у каждого свои
                         │  (тег)   │   │ (develop)  │   web · api · worker · db
                         └──────────┘   └────────────┘
```

Наружу смотрит только Traefik. У стендов нет ни одного порта на хосте — ни публичного, ни
loopback: на сервере `127.0.0.1` в одном ssh-туннеле от «публичного».

## Что нужно от Mika

| # | Что | Зачем |
|---|---|---|
| 1 | Доступ на сервер по ssh-ключу (не пароль) | без него ничего |
| 2 | Что за машина: сколько vCPU и памяти, какой Linux, стоит ли Docker | минимум 2 vCPU / 2 ГБ (практики §2); ev8.ge на этой же машине? |
| 3 | Два поддомена, A-записи на IP сервера | `ops.ev8.ge` — прод, `test.ops.ev8.ge` — тест (имена на ваш вкус) |
| 4 | Адрес для Let's Encrypt | письма об истечении сертификата |
| 5 | Пароль первого владельца | вводите вы, я его не вижу и не придумываю |

**Чего я не делаю:** не покупаю хостинг, не завожу учётки, не ввожу ваши пароли и не храню их.
Три машинных секрета (`POSTGRES_PASSWORD`, `SESSION_SECRET`, `WORKER_TOKEN`) генерируются на сервере
`openssl rand -base64 48` и остаются в `deploy/*.env` там же — их не набирает человек и не знает никто.

## Установка, по шагам

### 1. Один раз на машине

```bash
docker network create ev8-edge
cd /srv/ev8-ops && cp deploy/traefik/.env.example deploy/traefik/.env   # вписать ACME_EMAIL
docker compose -p ev8-edge -f deploy/traefik/docker-compose.yml up -d
```

Проверка: `curl -I http://<домен>` отвечает редиректом на https. Если нет — A-запись ещё не
разошлась, Let's Encrypt сертификат не выдаст. Сначала DNS, потом всё остальное.

### 2. Тестовый стенд (`develop`)

```bash
cp deploy/test.env.example deploy/test.env     # заполнить; секреты — openssl rand -base64 48
docker compose -f docker-compose.yml -f docker-compose.stand.yml -f deploy/server.yml \
  --env-file deploy/test.env -p ev8-ops-test up -d --build
```

Первый запуск сам накатит миграции и заведёт владельца из `OWNER_EMAIL`/`OWNER_PASSWORD`
(только на пустой базе). Проверка: `https://test.ops.ev8.ge/api/health` → `{"ok":true}`.

### 3. Прод (тег)

То же самое с `deploy/prod.env` и `-p ev8-ops`, но **из рабочего дерева на теге**:

```bash
git fetch --tags && git checkout 1.0.0
docker compose -f docker-compose.yml -f docker-compose.stand.yml -f deploy/server.yml \
  --env-file deploy/prod.env -p ev8-ops up -d --build
```

Практики §2: прод собирается только по тегу на `main`, красное до образа не доезжает. Пока это
правило держит человек; как только появится CI на сервере — переносим туда.

### 4. Копии

```bash
crontab -e
# каждый день в 04:10 по Тбилиси
10 4 * * * cd /srv/ev8-ops && BACKUP_DIR=/srv/ev8-backups deploy/backup.sh ev8-ops >> /var/log/ev8-backup.log 2>&1
```

`backup.sh` не просто снимает дамп: он восстанавливает его в одноразовую базу и считает строки.
Файл, который не восстановился, не считается копией и роняет задание с ошибкой в лог.

**Раз в месяц — руками:** свежий дамп на внешний диск, вне сервера и вне облака, которое
синхронизируется само. В дампе живые имена, телефоны и личные номера клиентов.

## Что проверить в первый день

1. `https://<прод>/api/health` → `{"ok":true}`, сертификат валиден, http редиректит на https.
2. `docker compose -p ev8-ops ps` — четыре контейнера, `db` и `api` healthy.
3. Ни одного порта наружу, кроме 80 и 443: `ss -tlnp | grep -v 127.0.0.1`.
4. Вход владельца работает; после первого входа пароль сменить в «Мой вход», строку
   `OWNER_PASSWORD` в `prod.env` очистить.
5. `deploy/backup.sh ev8-ops` — прошёл и написал «restored».
6. Журнал: в «Настройки → Журнал» видны входы — значит, аудит пишется на проде.

## Когда что-то не так

- **Сертификат не выдаётся** — DNS не указывает на эту машину, или 80-й порт занят другим
  веб-сервером (ev8.ge). Traefik должен быть единственным, кто слушает 80 и 443.
- **Стенд не поднимается с `variable is not set`** — в `deploy/*.env` пустая строка. Это защита,
  а не ошибка: `docker-compose.stand.yml` не даёт запустить прод с подставленным умолчанием.
- **Изменения не видны** — `--build`: web отдаёт собранный бандл.
- **Откат** — `git checkout <предыдущий тег>` и та же команда запуска. История прода = список тегов.
