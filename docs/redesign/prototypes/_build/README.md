# Сборка прототипов

Прототипы — статичный HTML без JavaScript. Каждый файл собирается скриптом из общих частей
(`proto_base.py`: токены из `apps/web/src/styles/tokens.css`, блок токенов-предложений, стили, значки,
рамки телефона и ноутбука), чтобы экраны не расходились между собой.

```bash
cd docs/redesign/prototypes/_build && for f in p_*.py; do python3 $f; done
```

Правка экрана — в его `p_*.py`, потом пересборка. HTML-файлы в `prototypes/` не правятся руками.
