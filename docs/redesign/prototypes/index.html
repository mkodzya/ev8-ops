Как смотреть

  • Каждый кадр телефона прокручивается внутри рамки.
  • Подпись под кадром объясняет решение и называет пункт аудита или ТЗ.
  • Грузинский текст — из словаря интерфейса (носителем не вычитан, register #15) или помечен как предложение.

Решения Mika после А4

  • В1. Удержание из залога решает один владелец (D18).
  • В9. Договор и акт — из EV8 Ops, на подпись без повторного ввода: Signify API или подпись на экране (D17).

  • Отчёт недели и загрузка парка, настройки, журнал — волна 6.
  • Перенос действующих аренд и остатков — волны 3 и 5.
