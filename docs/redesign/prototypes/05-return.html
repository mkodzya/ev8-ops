Решения и умолчания

  • В1 (Mika) — удержание решает один владелец, второго подтверждения нет (D18).
  • Q17 — опоздание по 30 ₾/день считается, только если указан плановый возврат.
  • Потеря ключа 250 ₾ по договору; в примере владелец удержал из неё 150 — сумма правится, причина в журнале.
