# «Пересмотреть решение по залогу» — грузинские строки: на вычитку

Дата: 25.10.2026. Разработчик. Строки написал не носитель языка. Слова «დეპოზიტი» [depoziti] («залог»),
«დაკავებულია» [dakavebulia] («удержано»), «დასაბრუნებელი» [dasabrunebeli] («к возврату»), «დაბრუნებულია»
[dabrunebulia] («возвращено»), «ხელზეა» [khelzea] («на руках»), «დავალიანება» [davalianeba] («долг»),
«სავალდებულოა» [savaldebuloa] («обязательно»), «დაბრუნების აქტი» [dabrunebis akti] («акт возврата») взяты из
словаря продукта; «გადახედვა» [gadakhedva] («пересмотр») и «იყო → იქნება» [iqo → iqneba] («было → станет») — новые.
Залог возвращают, а не «выдают» (issue #9, пункт 5): `npm run guard:words` теперь следит и за этими ключами.
Источники — `apps/web/src/i18n/deposit-revise.ts`, `errors.codes.deposit_undecided` в `apps/web/src/i18n/ka.ts`,
`feedWords['deposit.revise']` в `apps/web/src/i18n/wave4.ts`. Правило — ADR-0046. Примеры выдуманы: аренда R-…,
решение 14.10.2026, долг 150 ₾.

## Вопросы к вычитке

1. «რატომ ვხედავთ ხელახლა» («почему пересматриваем») — естественно ли, или лучше «გადახედვის მიზეზი»?

   «მოათავსეთ» для файла?
