# «Склад», «Изменить данные», «Это не возврат» — грузинские строки: на вычитку

Дата: 28.10.2026. Разработчик. Строки написал не носитель языка. Задача — GitHub issue `mkodzya/ev8-ops#19` директора
(27–28.10.2026), Mika «А» 28.10.2026; правила — ADR-0048 (дополнение 28.10.2026, меню) и ADR-0034 (дополнение
28.10.2026, «Это не возврат»). Источники: `apps/web/src/i18n/ka.ts` (`nav`, `shell.tabs`, `errors.codes`),
`apps/web/src/i18n/vehicle-details.ts`, `apps/web/src/i18n/drive.ts`, `apps/web/src/i18n/wave4.ts` (`feedWords`).
Даты и номера в примерах выдуманы. Слова — по словарю issue #9: возврат мопеда — «დაბრუნება», «Сегодня» —
«„დღეს“», дата прихода — «მოსვლის თარიღი», как уже в продукте.

## Вопросы к вычитке

1. «ნაწილები» для вкладки «Запчасти» — понятно ли, что это запчасти склада? Или нужно «სათადარიგო ნაწილები»
   («запасные части»), если помещается во вкладку на телефоне?
2. «ეს დაბრუნება არ არის» — кнопка в строке рядом с «ქირაობის დახურვა». Не длинно ли для кнопки на телефоне 375 px?
   Короче — «არ დაბრუნებულა» («не возвращён»)?
3. «მონაცემების შეცვლა» — «Изменить данные» мопеда: цвет, год, дата прихода. Подходит ли «მონაცემები» для этих трёх, или
   лучше «დეტალები»?
4. «ხაზი მოიხსნა» — «строка убрана» с «Сегодня»: так ли говорят о строке очереди?
