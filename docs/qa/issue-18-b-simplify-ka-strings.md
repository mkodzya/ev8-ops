# Упрощения по аудиту (issue #18, часть B) — грузинские строки: на вычитку

Дата: 28.10.2026. Разработчик. Строки написал не носитель языка. Задача — GitHub issue `mkodzya/ev8-ops#18` директора
(25.10.2026), часть B; Mika 28.10.2026: «А», «Да, без отмены», «Одно правило календаря». Правила — ADR-0048, ADR-0045
и ADR-0016 (дополнения 28.10.2026). Источники: `apps/web/src/i18n/simplify.ts` (новые строки), `ka.ts`, `wave3.ts`,
`wave4.ts`, `drive.ts`, `goods.ts`, `inbound.ts`, `pickup-date.ts`. Числа и номера в примерах выдуманы.

Правило этой ветки: **грузинские слова Kardu не меняются.** Где русское слово выровнено, а по-грузински у понятия
уже одно слово — оно и взято. Где по-грузински у одного понятия два слова, ветка их не трогает и спрашивает (§3).
Новые строки (§1) написаны из уже принятых в продукте слов, где они есть.

## 3. Вопросы Kardu: одно понятие — два грузинских слова

По-русски выровнено, по-грузински ветка ничего не меняла. Ответьте «да» — поменяем на предложенное, или назовите своё.

1. **Статус мопеда в ремонте.** По-русски теперь везде «В ремонте» (было и «В сервисе»), раздел — «Ремонты».
   По-грузински статус — «სერვისში» (`states.service`, плитка «Сегодня», события «სერვისში» / «სერვისიდან»,
   заголовок нового блока), а раздел — «რემონტები». Сделать статус «რემონტში» (remont'shi)?
2. **Аванс.** По-русски «Аванс клиента» и в «Разобрать», и как вид платежа (было «Аванс по аренде»). По-грузински:
   ответ «Разобрать» — «კლიენტის ავანსი», вид платежа — «ქირის ავანსი» (kiris avansi). Сделать везде «კლიენტის
   ავანსი»?
3. **Наличные в банк.** По-русски «Внесение наличных в банк» (было «Внёс в банк» и «Сдача наличных в банк»; «сдача» —
   слово кассы). По-грузински: ответ «Разобрать» — «ნაღდის ბანკში შეტანა», запись — «ბანკში შევიტანე» (bank'shi
   shevit'ane, «я внёс в банк»). Сделать запись «ნაღდის ბანკში შეტანა»?
4. **Одна строка — несколько записей.** По-русски «Несколько услуг» и для поступлений, и для списаний (было
   «Разнести» у списаний). По-грузински: поступления — «რამდენიმე მომსახურება», списания — «განაწილება» (ganats'ileba,
   слово issue #9, п. 27). Сделать и у списаний «რამდენიმე მომსახურება»?
5. **Возврат мопеда как действие.** По-русски «Вернуть мопед» (было «Принять возврат»). По-грузински везде одно —
   «დაბრუნების მიღება» («приём возврата»); оставить или «მოპედის დაბრუნება» (mop'edis dabruneba), как «მოპედის
   გაცემა» у выдачи?
6. **Вкладки «Настроек».** По-русски «Статьи расходов» / «Статьи доходов»; по-грузински взяты заголовки этих экранов —
   «ხარჯების კატეგორიები» / «სხვა შემოსავლის კატეგორიები». Подходят ли они для вкладки, или короче?
7. **«К звонку»** — «დასარეკი» (dasarek'i, «к звонку, то, кому позвонить») — новое слово первой вкладки «Оплат по
   графику». Подходит?
