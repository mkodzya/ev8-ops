## Отклонения от спецификации

1. **Клавиши в «Разобрать» на ноутбуке** (§3.2: таблица строк и панель выбранной строки, ↑↓ / Enter / «/» / N) —
   не сделаны: на ноутбуке та же лента карточек. Следующим раундом, если нужно для приёмки.
2. **«Отменить» после привязки строки** — отменяет созданный платёж; строка возвращается в очередь. «Да, это он»
   (связь с внесённым) и «Расход компании» отменяются только владельцем через «Разобрано правилами → Отвязать» /
   не отменяются — сообщение без «Отменить».
3. **Залоги, решённые до волны**, считаются выданными (`paid_out_before_tetri` = решено вернуть): иначе «К выдаче»
   открылась бы всеми старыми возвратами. Предположение: залог отдавали в день возврата. Если нет — поправить данными.
4. **Касса считает с 18.09.2026** (момент миграции): история из Odoo — не наличные в руках людей системы.
5. **Взнос наличных** узнаётся по словам «Setana / naRdi fulis Setana / cash deposit / შეტანა» — образца настоящей
   строки BOG/TBC со взносом нет (Q2-b). Без слова строка идёт в «Разобрать» с подсказкой, если совпала с «Внёс в банк».
6. **Период в «Платежах»** — «эта неделя» с понедельника; «свой» период не сделан (есть: эта, прошлая, месяц, всё).
7. **«Кто внёс» и фильтры** на телефоне — выпадающие списки, не лист.
8. **Долг по записи в чипе** не больше общей цифры клиента (деньги на счету уменьшают долг), поэтому чип «долг»
   может быть меньше суммы строк «из чего сложено».
9. **Предел файла** — 8 МБ (сервер); в прототипе было 10.
10. **Строка «Недавно»** в выборе «от кого» (прототип) — нет: сразу поиск.
