## Тестировщику

- Роли на QA: владелец — учётка Mika; директор и менеджер — `demo.director@ev8.test`, `demo.manager@ev8.test`.
  Входит Mika.
- **401 → вход → та же страница** без удаления сессий вручную: Mika входит менеджером в обычном окне и
  владельцем в окне инкогнито (у окон разные куки). Менеджер открывает карточку аренды; владелец в
  «Настройках → Люди» задаёт менеджеру новый пароль (это закрывает сессии менеджера). Менеджер жмёт
  «Провести платёж» → вход → после входа — та же карточка. После теста пароль менеджера на QA — новый.
- **Механик:** владелец на QA создаёт учётку механика с обычным адресом (не `@ev8.test`), Mika входит ею.
- **Guard:** добавьте во временной ветке `throw badRequest('new_code_for_test', '…')` в любой роут и
  запустите `npm run guard` — должен упасть `errors-guard`. В `develop` не коммитить.
- «Нет связи»: `docker stop ev8-ops-qa-api-1` при открытой странице, затем `docker start ev8-ops-qa-api-1`.
  Если при остановленном API перезагрузить страницу целиком, откроется вход — это ожидаемо: приложение не
  может узнать, кто вошёл.
