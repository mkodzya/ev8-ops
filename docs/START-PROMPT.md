# Промпт для нового окна Claude Code (скопировать целиком)

Ты работаешь в репозитории `~/Desktop/ev8-ops-platform` — это EV8 Ops,
собственная операционная система E‑Motion Motors LLC (электромопеды, Тбилиси),
которая полностью заменяет Odoo. Я — Mika, владелец. Общение по‑русски, код и
коммиты по‑английски.

Сначала прочитай целиком, в этом порядке: `CLAUDE.md`, `docs/handoff.md`,
`docs/spec/ev8-ops-tz-v1.1.html`, `docs/design/brand.md`. Потом
`~/Desktop/EV8-ops/odoo-data-checklist.md` — журнал того, что уже сделано в Odoo
и какие данные там реальные. Ничего не восстанавливай по памяти: источники
только эти файлы, Odoo (read‑only через `tools/odoo_rpc.py`), Google Drive и сайт ev8.ge.

Незыблемые правила: не выдумывать данные; ничего не удалять в Google Drive;
не работать с банковскими и любыми credentials (ключи регистрирую и храню я,
код читает их из секретов сервера); в Odoo только чтение.

Как работаем: поэтапно, вопросы по ходу и по одному, когда решение реально
ветвит работу; без пошаговых комментариев между действиями — сделал, проверил,
коротко доложил. Проверяй, запуская: docker compose, браузер, тесты.
Визуальные варианты присылай мне HTML‑файлом без JavaScript (мой просмотрщик
его не выполняет). Как в Self Platform (`~/Desktop/selfstudio-OPS`): тот же стек,
те же конвенции, деплой через git на два стенда, когда стенды появятся.

Задача сейчас — Этап 1, шаг 1 из `docs/handoff.md`: скаффолд монорепо
(`apps/api` Fastify 5 + Prisma 7 + PostgreSQL 16, `apps/worker`, `apps/web`
React 18 + Vite 6 PWA с тремя языками ka/ru/en и i18n‑guard, `packages/shared`),
compose с api/worker/web поверх существующего `db`, `.command`‑скрипты запуска,
первая миграция с сущностями Модель / Мопед / Клиент / Аренда / Период / Залог /
Акт и журналом изменений, роли owner / director / manager / mechanic / accountant.

цифры из `docs/handoff.md`, п. 3.
