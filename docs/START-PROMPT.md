собственная операционная система E‑Motion Motors LLC (электромопеды, Тбилиси), которая полностью
заменяет Odoo. Я — Mika, владелец. Общение по‑русски, код и коммиты по‑английски.

**Прочитай целиком, в этом порядке:** `CLAUDE.md` → `docs/handoff.md` → `docs/practices.md` →
`docs/design/ux.md` → `docs/design/brand.md` → `docs/spec/ev8-ops-tz-v1.1.html` → потом
`~/Desktop/EV8-ops/odoo-data-checklist.md` (журнал того, что уже сделано в Odoo и какие данные реальные).
Ничего не восстанавливай по памяти: источники только эти файлы, Odoo (read‑only через
`tools/odoo_rpc.py`), Google Drive и сайт ev8.ge.

**Незыблемые правила:** не выдумывать данные; ничего не удалять в Google Drive; не работать с
банковскими и любыми credentials (ключи регистрирую и храню я, код читает их из секретов сервера);
в Odoo только чтение; в репозитории ни личных данных, ни снимков, ни выписок.

**Протокол работы — как в студии Self (`CLAUDE.md`, раздел «Сессии»):** старт с `git status` и
`git log -3`; ветка `develop` — рабочая, задача — в worktree `../_worktrees/ev8-ops-<topic>` на
`feature/<topic>`; коммит и push по ходу, заголовок — фраза‑вердикт в стиле NYT; тяжёлые команды
(compose, Vite, Prisma, tests) под бюджет памяти 8 ГБ, по одной; решения — ADR в `docs/adr/`.
Поэтапно, вопросы по ходу и по одному, когда решение реально ветвит работу; без пошаговых
комментариев между действиями — сделал, проверил, коротко доложил. Проверяй, запуская. Визуальные
варианты присылай HTML‑файлом без JavaScript (мой просмотрщик его не выполняет; допустимы CSS‑only
переключатели). Каждый этап заканчивается демо на тестовом стенде, а не докладом.

**Практики, которые обязательны с первого коммита (`docs/practices.md`):** один JSON‑источник
токенов бренда и ноль hex‑литералов в компонентах (проверка в CI); параметризованный SQL, ни одной
интерполяции ввода; guard по роли на каждом маршруте; первый владелец из env при пустой базе, без
паролей в сидах; сырые данные (строки выписок, вебхуки) хранятся как пришли и не переписываются;
словарь метрик с ID и формулами; каждое требование с методом проверки (Test / Demonstration /
Inspection / Analysis); сид не перезаписывает введённое пользователем; деплой прода только по
тегу `X.Y.Z` на `main` с гейтом тестов; конфигурация в runtime из env, не в билде.

**UX/UI (`docs/design/ux.md`):** экран отвечает на один вопрос; главное действие — большая
pill‑кнопка внизу на телефоне; состояние — цвет + форма + слово; мастера по шагам; «оплачено по»
и «долг» вместо списков счетов; пустое состояние предлагает следующее действие; одна лента истории;
поиск по последним 4 знакам VIN; тёмная тема как режим токенов; Noto Sans Georgian везде.
Улучшения U1–U15 из `ux.md` входят в этапы 1–2, страница `/design` (Foundations) — в этап 1.
