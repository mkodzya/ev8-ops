## 1. С чего начать новую сессию

1. `git status`, `git pull --ff-only`, `git log -3`.
2. Прочитать: `CLAUDE.md` (он же подключает правила книги проекта) → этот файл →
   `docs/practices.md` → `docs/design/ux.md` → `docs/design/brand.md` → нужные ADR в `docs/adr/`.
3. Бизнес-правила, словарь, решения владельца и открытые вопросы — **в книге проекта**
   `~/Developer/ev8/handbook` (GitHub `mkodzya/ev8-handbook`): `project.md`, `business/`,
   `register.md`, `knowledge.md`. Правило бизнеса живёт в книге, код его исполняет (ADR-0002 книги).
4. Стенды: сервер — §2а; ноутбук — `docker compose ps`, если лежит — `docker compose up -d` (тяжёлая
   задача, одна за раз).
5. **Сессии ведут двое** — Mika и Kardu, каждый своим Claude (с 28.09.2026). Оба вливают в `develop`,
   релизы — только Mika. Как устроено у Kardu — `docs/onboarding.md`.
6. Следующий шаг — в §2а, внизу. План перехода бизнеса целиком — `docs/cutover.md`.
7. Редизайн тремя ролями (дизайнер, разработчик, тестировщик) закрыт с 1.0.0. Если Mika снова зовёт роли —
   `docs/agents/README.md`, роль задаётся первой строкой («Прочитай docs/agents/<роль>.md»).

## 5. Решения, которые из кода не видны

Из прошлой версии, всё ещё верно:

- **Ничего производного не хранится:** «оплачено по», просрочка, себестоимость партии, остатки,
  экономика мопеда складываются из строк — исправление сразу меняет ответ.
- **Курс валюты не хранится:** оплаченные GEL делятся по строкам инвойса пропорционально, остаток —
  методом наибольшего остатка. Контроль: XL1200 = 1 689,29 GEL.
- **Залог — не выручка;** удержанное приходит как ремонт за счёт клиента.
- **Мопед без себестоимости не получает итога;** незаполненное — не ноль.
- **Расход со склада при нехватке не запрещён:** остаток уходит в минус, для этого есть инвентаризация.
- **Склад — скользящее среднее.** Комиссия эквайринга — расход компании. Ночной прогон недель живёт в
  API, воркер — только часы. Маршрут без scope доступен только владельцу. Файлы — в Postgres. Тема
  только светлая.

Добавилось 15–17.09:

- **Мопед отвечает на три вопроса** — парк (`vehicles.pool`, NULL = «никто не решил»), состояние (из
  событий), точка (`locations`, снимается при выдаче). Перевод между парками — событие; отменить может
  тот же человек, последний перевод, в течение 10 минут (ADR-0005).
- **Цвет:** код хранится как есть (`black`…), сырые значения из Odoo не переписываются, `colorOf()`
  понимает грузинские, английские и русские написания; в PDF — `colorOnPaper()`.
- **Модели:** себестоимость пишет только приход партии (до него — цифра из Odoo с пометкой); флаги
  `for_rent/for_sale` в продукте не читаются; дубль по бренду и названию без учёта регистра — 409
  `duplicate_model` с id существующей (ADR-0011).
- **Drawer рисуется в `body` через портал;** окна могут открываться друг над другом, Escape закрывает
  верхнее.
- **Дизайн-токены** — один источник `packages/shared/tokens.json` → `scripts/tokens.mjs`; в компонентах
  ни одного цвета литералом (guard). Плотность, анимация (`--ease`, `--enter`), чернила пилюль состояний —
  токены.

## 8. Подводные камни окружения

- **Репозиторий не держать в iCloud** (git зависает) и не класть в папку с `:` в имени (Docker bind
  mount ломается: `invalid volume specification`). Сейчас путь чистый.
- В iCloud попадали дубли вида `schema 2.ts` — ломали typecheck.
- Изменение не видно на стенде → бандл не пересобран: `--build`, при необходимости `--force-recreate`.
- `sticky`-ячейки создают свой контекст наложения: меню строки рисуется порталом (`RowMenu`).
- Mac 8 ГБ: одна тяжёлая задача за раз.
- Диск: Docker Desktop не стартует при заполненном диске («no space left on device» в
  `~/Library/Containers/com.docker.docker/Data/log/host/com.docker.backend.log`) — освободить место и
  перезапустить Docker Desktop.
- **`${VAR:?…}` в compose отвергает и пустое значение, не только отсутствующее.** Так прод однажды не
  стартовал бы после очистки `OWNER_PASSWORD` (исправлено в 1.0.2). Разовые значения — `${VAR-}`.
- **VPN на Mac резолвит через 100.65.0.1**, который не знает `*.trycloudflare.com` и может отставать по
  новым записям. Проверять DNS публичным резолвером: `dig +short @1.1.1.1 ops.ev8.ge`.
- **Пароли в базу разработчик не пишет** — auto mode это запрещает, и правильно. Сменить пароль —
  Mika одной командой `deploy/set-password.sh` (раздел «Забытый пароль» в `deploy/README.md`).
- Шлюз QA (Vite preview) на упавший API отвечает `500 text/plain` без длины — поэтому «нет связи»
  распознаётся по отсутствию JSON, а не по коду.
