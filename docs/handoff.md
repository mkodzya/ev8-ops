## 3. Как проверять (Node на Mac нет — всё в контейнере)

**Два стенда.** Рабочий — http://localhost:5175, живые данные, сценарии с записью на нём не проводят.
QA — **http://127.0.0.1:5185** (именно 127.0.0.1: куки по хосту, на двух localhost была бы одна
сессия), копия базы рабочего, управление `scripts/qa-stand.sh up | images | refresh | down`. Подробно —
`docs/qa/README.md`.

Гейт в worktree (node_modules берутся из основного checkout, Prisma-клиент генерируется в worktree):

```bash
R=~/Desktop/claude-mika/ev8-ops-platform; W=~/Desktop/claude-mika/_worktrees/ev8-ops-<topic>
nice -n 10 docker run --rm -m 3g --network ev8-ops-platform_default \
  --mount "type=bind,source=$W,target=/w" --mount "type=bind,source=$R/node_modules,target=/w/node_modules" \
  -w /w -e DATABASE_URL=postgresql://ev8ops:ev8ops@db:5432/ev8ops_test \
  -e SESSION_SECRET=test-secret-that-is-long-enough-for-checks-0001 \
  -e WORKER_TOKEN=test-worker-token-that-is-long-enough-0001 node:22-alpine \
  sh -c "npm -w @ev8/api run generate >/dev/null 2>&1; npm -w @ev8/api run migrate; npm run typecheck; npm run guard; npm test; npm -w @ev8/web run build"
```

- Без `generate` в новом worktree все тесты API падают (нет `src/generated/prisma`) — это не баг кода.
- Тесты не накатывают миграции сами: новая миграция без `migrate` в гейте даёт 500 в тестах (`relation … does not exist`).
- Стенд после слияния: `docker compose up -d --build web api` (web отдаёт собранный бандл —
  без пересборки изменения не видны), затем `scripts/qa-stand.sh images`. Порты: web 5175, api 8082,
  db 5433; QA — 5185, 8092, 5443. Открытая вкладка держит старый бандл — перезагрузить страницу.
- Запросы к данным стенда только чтением:
  `docker compose exec -T db psql -U ev8ops -d ev8ops -c "…"`.
- Тесты гонять дважды подряд на одной базе, если трогали уборку в `test/globalSetup.ts`.

## 5. Решения, которые из кода не видны

Из прошлой версии, всё ещё верно:

- **Ничего производного не хранится:** «оплачено по», просрочка, себестоимость партии, остатки,
  экономика мопеда складываются из строк — исправление сразу меняет ответ.
- **Курс валюты не хранится:** оплаченные GEL делятся по строкам инвойса пропорционально, остаток —
  методом наибольшего остатка. Контроль: XL1200 = 1 689,29 GEL.
- **Залог — не выручка;** удержанное приходит как ремонт за счёт клиента.
- **Мопед без себестоимости не получает итога;** незаполненное — не ноль.
- **Расход со склада при нехватке не запрещён:** остаток уходит в минус, для этого есть инвентаризация.
- **Склад — скользящее среднее.** Комиссия эквайринга — расход компании. Ночной прогон недель живёт в
  API, воркер — только часы. Маршрут без scope доступен только владельцу. Файлы — в Postgres. Тема
  только светлая.

Добавилось 15–17.09:

- **Мопед отвечает на три вопроса** — парк (`vehicles.pool`, NULL = «никто не решил»), состояние (из
  событий), точка (`locations`, снимается при выдаче). Перевод между парками — событие; отменить может
  тот же человек, последний перевод, в течение 10 минут (ADR-0005).
- **Цвет:** код хранится как есть (`black`…), сырые значения из Odoo не переписываются, `colorOf()`
  понимает грузинские, английские и русские написания; в PDF — `colorOnPaper()`.
- **Модели:** себестоимость пишет только приход партии (до него — цифра из Odoo с пометкой); флаги
  `for_rent/for_sale` в продукте не читаются; дубль по бренду и названию без учёта регистра — 409
  `duplicate_model` с id существующей (ADR-0011).
- **Drawer рисуется в `body` через портал;** окна могут открываться друг над другом, Escape закрывает
  верхнее.
- **Дизайн-токены** — один источник `packages/shared/tokens.json` → `scripts/tokens.mjs`; в компонентах
  ни одного цвета литералом (guard). Плотность, анимация (`--ease`, `--enter`), чернила пилюль состояний —
  токены.
