# Три роли: аналитик, разработчик, тестировщик

Каждая роль — отдельная сессия Claude Code в папке `ev8-ops-platform`. Запуск сессии — одна строка:

> Прочитай `docs/agents/<роль>.md` и работай по нему.

Роли работают **по очереди**, а не одновременно: Mac на 8 ГБ, код меняет один писатель, решения —
за Mika. Передают работу через файлы (`docs/qa/README.md`, таблица «Файлы цикла»).

```
Аналитик ──► docs/audit/2026-09-audit.md + docs/spec/ev8-ops-tz-v2.md
                              │  Mika утверждает ТЗ
Разработчик ◄─────────────────┘  блок N ──► docs/qa/block-N-ready.md
                                                   │
Тестировщик ◄──────────────────────────────────────┘
      └──► docs/qa/block-N-report.md ──► разработчик чинит ──► тестировщик перепроверяет
                                                   │
                         нет блокеров ──► Mika принимает ──► блок N+1
```

## Порядок

| Шаг | Сессия | Что сказать | Перед этим |
|---|---|---|---|
| 1 | «EV8 · Аналитик» (Opus, effort high) | «Прочитай docs/agents/analyst.md и работай по нему» | Войти в Chrome на http://localhost:5175 |
| 2 | Mika | прочитать и утвердить ТЗ | — |
| 3 | «EV8 · Разработчик» | «Прочитай docs/agents/developer.md. ТЗ утверждено, начинай блок 1» | — |
| 4 | «EV8 · Тестировщик» | «Прочитай docs/agents/tester.md. Тестируй блок 1» | Войти в Chrome на http://127.0.0.1:5185 под нужной ролью |
| 5 | Разработчик | «Чини по docs/qa/block-1-report.md» | — |
| 6 | Тестировщик | «Перепроверь блок 1» | — |
| 7 | Mika | посмотреть блок, сказать разработчику «принято, блок 2» | отчёт без блокеров |

Шаги 5–6 повторяются, пока в отчёте есть блокеры. Раз в 2–3 принятых блока разработчик предлагает
релиз и обновляет `docs/handoff.md`.
