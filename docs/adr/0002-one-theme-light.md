# 0002. Одна тема, светлая

Дата: 14.09.2026 (записано задним числом 15.09.2026). Статус: принято.
Подтверждено повторно вечером 14.09.2026.

## Контекст

`brand.md` описывает тёмный вариант палитры (`#0b0b0b` с зелёным `#a2b9a2` и
светлым логотипом), `docs/design/ux.md` предлагал U13 — тёмную тему как режим
токенов, «для сервиса вечером и на улице». Команда работает с телефона на
улице, аргумент не выдуман.

Против: каждый экран нужно проверить дважды, каждый контраст посчитать дважды,
и половина дефектов тёмной темы обнаруживается не автором.

## Решение

Одна тема, светлая. Тёмная не строится. U13 вычеркнут из `ux.md` с датой и
причиной.

## Последствия

- `packages/shared/tokens.json` — один набор значений, без ключа режимов.
  Возврат тёмной темы стоит второго набора значений в том же файле, а не
  второй таблицы стилей: структура токенов этого не запрещает.
- Тёмной остаётся ровно одна поверхность — боковая панель на ноутбуке
  (`--rail`), и у неё свои пять токенов.
- `<meta name="color-scheme" content="light">`: браузер не перекрашивает
  формы по системной настройке.
