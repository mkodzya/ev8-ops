შეკეთება EV8 Ops-ში — პლანშეტიდან

Ремонт в EV8 Ops с планшета мастерской — инструкция главного механика на один экран. Слева — на планшете (ka), справа — по-русски.

  1. 1

    შესვლა

    პლანშეტზე დააჭირეთ თქვენს სახელს და აკრიფეთ PIN → შესვლა. წასვლისას — გასვლა. 10 წუთი თუ არაფერს აჭერთ, სისტემა თვითონ გამოგიყვანთ.

    Вход

    Нажать своё имя, набрать PIN → «Войти». Уходя — «Выйти». Без касаний 10 минут — выход сам.

  2. 2

    ახალი შეკეთება

    ＋ ახალი შეკეთება → მოპედი: VIN-ის ბოლო 4–6 სიმბოლო ან ნომერი სტიკერიდან → გარბენი და ოდომეტრის ფოტო → მიზეზი, რა გაფუჭდა, დაზიანების ფოტო → სამუშაოები ცნობარიდან → შეკეთების გახსნა.

    Новая заявка

    «＋ Новая заявка» → мопед по хвосту VIN или номеру с наклейки → пробег и фото одометра → причина, что сломалось, фото поломки → работы из справочника → «Открыть ремонт». Ваша заявка сразу в работе; заявка механика уходит вам на согласование.

  3. 3

    დამტკიცება

    „შეკეთება“ → ელოდება დამტკიცებას. ბარათში ნახეთ ფოტო, მიზეზი, გარბენი და სამუშაოები. სიის გარეთ სამუშაოს ჩაუწერეთ ნორმა (წთ). შემდეგ დამტკიცება ან უარყოფა — უარს მიზეზი აუცილებლად სჭირდება.

    Согласование

    «Ремонт» → «Ждут согласования». В карточке — фото, причина, пробег, работы. Работе «не из списка» впишите норму в минутах. «Согласовать» или «Отклонить» — отказ только с причиной: механик её увидит, мопед вернётся в парк.

  4. 4

    ახალი სამუშაო შეკეთების დროს

    შეკეთების ბარათში ＋ სამუშაო → აირჩიეთ ცნობარიდან ან ჩაწერეთ სიტყვებით → დასამტკიცებლად გაგზავნა. დამტკიცებულ სამუშაოს აგრძელებთ; ახალი ცალკე ელოდება.

    Нашлась ещё работа

    В карточке заявки «＋ Работа» → из справочника или словами → «Отправить на согласование». Согласованное продолжаете; новая работа ждёт одна. Ваша собственная работа записывается согласованной сразу.

  5. 5

    დახურვა

    ბარათში დახურვა → ფოტო შეკეთების შემდეგ (1-დან 5-მდე) → გარბენი → სად დგას მოპედი → შეკეთების დახურვა. მოპედი ბრუნდება ფლოტში „თავისუფალი“.

    Закрытие

    «Закрыть» → фото после ремонта (1–5) → пробег → где стоит мопед → «Закрыть заявку». Мопед снова «Свободен». Без фото «после» заявка не закроется.

კლიენტის ხარჯზე შეკეთებას ხურავს მფლობელი — თქვენ მხოლოდ დაამატეთ ფოტო „შემდეგ“.
Ремонт за счёт клиента закрывает владелец (он решает удержание из залога) — вы только добавляете фото «после».
